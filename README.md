# BRIDGE GROUP

Official corporate website for BRIDGE GROUP, with 17 language versions and an interactive WebGL experience.

## Publishing

GitHub Pages source: **main /docs**. The ready-to-publish HTML, CSS, JavaScript and images are in `docs/`; no build step or package installation is needed.

Primary domain: **bridgegroup.asia**.

## Languages

Korean, English, Japanese, Simplified Chinese, Traditional Chinese, German, French, Spanish, Portuguese, Russian, Arabic, Indonesian, Malay, Vietnamese, Thai, Turkish and Bengali.

The English company website screenshots are shared across the translated pages. EUM ECONOMY retains its Korean screenshot.

## Contact

Public contact: ceo@bridgegroup.asia. Inquiry forms use FormSubmit and the configured recipient mailbox; initial recipient verification is required by FormSubmit.

## DNS and email

DNS is managed by Cloudflare. Preserve the existing Cloudflare Email Routing MX, SPF, DKIM and other mail verification records when changing website DNS records.
